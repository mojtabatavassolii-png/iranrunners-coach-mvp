# بازبینی UX/UI

ابزار بازبینی دوره‌ای ظاهر و کاربردپذیری «گام». بخشی از اپ نیست و فقط داخل مرورگر تست اجرا می‌شه.

```bash
cd tools/ux-audit
npm install                       # فقط بار اول (Playwright)
node audit.js                     # اندازه‌گیری‌ها → out/report.md، out/report.json، out/shots/
node compare.js proposals.json    # تصویر قبل/بعد هر پیشنهاد → out/compare/
python3 -I palette.py ref.png     # رنگ‌های غالب یک اسکرین‌شات مرجع
```

| فایل | کار |
|---|---|
| `audit.js` | اندازه‌ی ناحیه‌ی لمس، کنتراست، فاصله‌ها، تایپوگرافی، تراز دوطرفه و سرریز صفحه در عرض‌های ۳۲۰ تا ۴۳۰ و هر دو زبان (`--css` برای سنجیدن یک پیشنهاد) |
| `compare.js` | تزریق CSS پیشنهادی در مرورگر تست و گرفتن عکس قبل/بعد (بدون تغییر اپ) |
| `palette.py` | استخراج رنگ‌های غالب اسکرین‌شات اپ‌های دیگه و نزدیک‌ترین توکن اپ |
| `lib.js` | صفحه‌هایی که بررسی می‌شن و آماده‌سازی مرورگر |
| `fixture.js` | داده‌ی ثابت تمرین، تا نتیجه‌ی اجراها قابل مقایسه باشه |
| `proposals.json` | پیشنهادهای اولین بازبینی (۱۴۰۵/۰۷/۲۲)، نمونه‌ی قالب |

روند کامل (اولویت‌بندی، گزارش، تحلیل سبک از اسکرین‌شات) در `.claude/skills/ux-audit` و `.claude/skills/style-match` نوشته شده.
